## Interpretation Warning

This register identifies implementation and governance gaps. It does not approve
canonical authority, assign institutional authority, resolve open decisions or
make branch-missing models and files available.

A documented crosswalk or capability map may reduce interpretation risk without
resolving the underlying runtime gap. A runtime role or route guard proves access
behavior only; it does not prove canonical authority.

## Status and Severity Model

Gap status values:

- `OPEN`: the implementation or governance requirement remains materially
  absent.
- `PARTIALLY_MITIGATED`: documentation, tests or compatibility mechanisms reduce
  interpretation risk, but the underlying runtime/governance requirement remains
  incomplete.
- `CONFLICTING`: committed runtime behavior materially contradicts a documented
  canonical separation.
- `RESOLVED`: committed evidence proves the gap is no longer present.
- `UNKNOWN`: evidence is insufficient.

Severity values:

- `Critical`: authority, publication, learner exposure, governance history,
  autonomous mutation, cross-artifact decisions or projection consistency can be
  materially corrupted.
- `Important`: auditability, revision semantics, evidence provenance,
  validation standing, application control or route/action parity is materially
  weakened.
- `Useful`: maintainability or usability improves, but safe human-controlled
  operation is not currently blocked.

2. Cross-artifact governance decision envelope.
3. Runtime role to canonical/institutional authority assignment.
4. Expected-version command contract.

8. Education review/publication separation.
9. Graph approval/promotion separation.

This sequence is planning guidance only. It is not approved implementation
authority.
