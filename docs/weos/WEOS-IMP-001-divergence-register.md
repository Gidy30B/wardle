# WEOS-IMP-001 Divergence Register

Status values: `OPEN`, `UNKNOWN`, `PLANNED`, `RESOLVED`.

Severity values: `CRITICAL`, `HIGH`, `MODERATE`, `LOW`, `INFORMATIONAL`.

Compatibility projection principle: existing fields such as `Case.editorialStatus`, `Case.approvedAt`, `Case.approvedByUserId`, `Case.publishedAt`, `DiagnosisEducation.editorialStatus`, `DiagnosisEducation.reviewedAt`, and `DiagnosisEducation.publishedAt` may remain temporarily as compatibility projections. Once canonical Governance Records and decisions become authoritative, these fields must be derived or synchronized only through governed command handlers and must not remain independent sources of truth.

Repository absence does not prove absence from external operational/manual governance processes.
