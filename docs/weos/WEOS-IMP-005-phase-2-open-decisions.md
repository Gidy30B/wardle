- Disposition: `REVIEW_REQUIRED`

## Decision Format

Each decision records decision ID, question, affected artifacts, current repository evidence, canonical constraint, available options, trade-offs, recommended direction, status, required evidence, target phase, and blocking or non-blocking effect.

## Register Scope

This register originated during Phase 2 and remains the active repository register for unresolved WEOS architecture decisions. Decisions registered during Phase 3 planning remain `Open` and do not imply Phase 2 completion, Phase 3 approval or implementation authorization.

The register records architecture questions and recommended directions. It does not approve an option, assign authority, resolve a gap or authorize schema, runtime, migration or enforcement work.

## Approved-With-Conditions Note

`WEOS-OD-021`, `WEOS-OD-018` and `WEOS-OD-022` authorizations are limited to Stage 1 contracts and do not authorize Prisma, persistence, runtime enforcement or dependent decisions. `WEOS-OD-019`, `WEOS-OD-023`, `WEOS-OD-024`, `WEOS-OD-025`, `WEOS-OD-026` and `WEOS-OD-027` remain open and unapproved unless a separate valid approval record exists.
