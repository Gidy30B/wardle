## Source-Boundary Notes

- `CaseReviewContextSnapshot`, `CaseEditorialDecision`, and `CaseReviewEvent`
  are `UNAVAILABLE_IN_BRANCH` as active database models and are not active
  implementation evidence.
- `case-review-governance.repository.ts` and
  `case-review-governance.repository.spec.ts` are `UNAVAILABLE_IN_BRANCH` for
  committed runtime evidence.
- `workspaceActionRegistry.ts` is `FILE_NOT_IN_BRANCH`; local uncommitted
  presence does not establish branch behavior.
- Branch-missing action files such as `teachingRuleActions`, `evidenceActions`,
  `reasoningPathActions`, and `clueRevisionActions` are not active implementation
  evidence in this map.
