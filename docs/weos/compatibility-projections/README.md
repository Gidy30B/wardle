# WEOS Compatibility Projections

Stage 1 defines repository-native contracts only. This directory is not a Prisma schema, not a migration, not runtime-integrated and not a projection synchronization worker.

Compatibility projections support existing runtime reads but do not independently establish canonical authority, approval, publication, playability, generatability, learner exposure, lifecycle standing, clinical authority or institutional authority. Every operational projection requires exactly one approved canonical owner. Unresolved ownership remains unresolved.

Registry membership does not approve an owner. Only `APPROVED` definitions may participate in pure operational evaluation. The production projection registry is empty and the production projection inventory is empty. Representative fields discussed in WEOS-OD-019 are migration analysis only; no production owner was invented.

Direct-write locations are evidence, not ownership. Writer and consumer inventories may be incomplete, and missing inventory is not proof of no writers or readers. Stale commands permit no projection update. Drift detection performs no repair. Repair eligibility performs no repair. Legacy observed values do not prove governance history. Runtime synchronization, repair execution, direct-write enforcement and consumer migration remain unauthorized.
