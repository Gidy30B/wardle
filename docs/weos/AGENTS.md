# WEOS Agent Instructions

## Required Reading

Before changing WEOS documentation or implementation evidence, read:

1. `docs/weos/AGENT-START-HERE.md`
2. `docs/weos/authority/STATUS-AND-PRECEDENCE.md`
3. `docs/weos/implementation/phase-0/PHASE-0-READINESS-REPORT.md`, when present
4. `docs/weos/implementation/phase-1a/PHASE-1A-READINESS-REPORT.md`, when
   present
5. `docs/weos/implementation/WEOS-DECISION-REGISTER.md`, when present
6. `docs/weos/implementation/WEOS-AMBIGUITY-REGISTER.md`, when present

## Documentation Rules

1. Do not infer document approval from existence, generation, review, validation,
   formatting, or inclusion in a package.
2. Preserve document status and authority wording exactly unless the task is
   explicitly authorized to update that status.
3. Generated and reviewed documents remain non-authoritative unless an approved
   authority record says otherwise.
4. Open decisions are never silently resolved.
5. Implementation evidence must record commit, branch, verification command, and
   observed result basis where practical.
6. Absence of an authority record means unresolved authority, not denial or
   approval.
7. Do not fabricate supersession, approval, reviewer, rationale, effective date,
   or historical authority.

## WEOS Phase Discipline

Documentation can index, compare, or report authority. It must not itself grant
authority unless it is an approved authority record created under the applicable
approved process.
