Inspection date: 2026-08-08

This inventory classifies the dirty worktree that existed before Phase 1A began.
It preserves the distinction between user work, Phase 0 documentation,
experimental WEOS implementation, and unknown changes. Phase 1A-created files
are not treated as pre-existing work.

Classification legend:

- `PHASE_0_EVIDENCE`: created by the completed Phase 0 task.
- `PHASE_1A_BOOTSTRAP`: repository-legibility, authority-index,
  environment-pin, execution-plan, or baseline preparation artifact created by
  Phase 1A.
- `USER_WORK`: unrelated or product work that Phase 1A/1A.5 must preserve.
- `EXPERIMENTAL_RUNTIME`: governance/editorial/WEOS implementation, schema,
  migration, dashboard, or service work that is not made canonical by Phase
  1A.5.
- `UNKNOWN`: purpose not proven by Phase 1A.5 inspection.
