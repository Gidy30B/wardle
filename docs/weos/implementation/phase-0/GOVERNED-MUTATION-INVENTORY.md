# WEOS Phase 0 Governed Mutation Inventory

Inspection date: 2026-08-08

This inventory lists mutation surfaces that should be considered governed under
WEOS. It records current runtime evidence only; it does not approve or redesign
the surfaces.

Status legend:

- `CURRENT_RUNTIME_DIRECT`: mutation exists in current runtime and is not routed
  through a shared WEOS governance kernel.
- `PARTIAL_WORKTREE_GOVERNANCE`: dirty working tree includes governance-related
  scaffolding, but it is not clean committed authority in this baseline.
- `COMPATIBILITY_PROJECTION`: mutation exists to keep legacy/current runtime
  behavior working.
- `BLOCKED_BY_OPEN_DECISION`: governance semantics depend on unresolved WEOS
  decisions.

## Inventory Conclusions

1. The mutation surface is broad and split across admin, education, diagnosis
   graph, gameplay, and script contexts.
2. Existing guards primarily establish route access, not documented authority to
   perform a specific governed command.
3. Compatibility projections are already part of runtime behavior and need an
   explicit owner before governance automation.
4. Dirty worktree governance additions are promising evidence, but cannot be
   treated as a clean baseline until reviewed, staged, and committed.
